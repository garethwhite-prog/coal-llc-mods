# 45-Tier Tank Arsenal

**Namespace:** $namespace  
**Compatibility:** Coal LLC v1.4.1.1+ (ModLoader 7.0.1)

---

## Overview
Adds 45 custom tank levels across Incendiary, Caustic, and Depleted Uranium variants with scaling ballistic shells.

---

## Technical Details (For Modders)
Hooks tanker.gd and management_screen.gd to dynamically inject and tier-sort tank equipment cards into the shop.

---

## Installation
1. Ensure **Coal LLC** has Godot ModLoader 7.0.1 installed.
2. Place the packaged .zip file into your Coal LLC/mods/ directory.
3. Manage or toggle this mod directly via the in-game **Mod Manager**.
