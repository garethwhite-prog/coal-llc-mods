# Tabatha Quests & Vacuum Levels 5-8

**Namespace:** $namespace  
**Compatibility:** Coal LLC v1.4.1.1+ (ModLoader 7.0.1)

---

## Overview
Extends NPC Tabatha's questline with Diamond, Uranium, and Moonstone tiers that reward high-capacity deep-strata vacuums.

---

## Technical Details (For Modders)
Hooks quest_scene_manager.gd to inject extended quest objectives and connects reward_vacuum.gd to high-tier vacuum equipment.

---

## Installation
1. Ensure **Coal LLC** has Godot ModLoader 7.0.1 installed.
2. Place the packaged .zip file into your Coal LLC/mods/ directory.
3. Manage or toggle this mod directly via the in-game **Mod Manager**.
