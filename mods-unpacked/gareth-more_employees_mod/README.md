# Executive Miners Expansion

**Namespace:** $namespace  
**Compatibility:** Coal LLC v1.4.1.1+ (ModLoader 7.0.1)

---

## Overview
Expands the workforce organisation chart with additional executive hierarchy tiers and automated high-yield miners.

---

## Technical Details (For Modders)
Hooks organisation_chart_2.gd _ready, refresh_all_icons, and _draw to inject custom rows and hierarchy connection lines.

---

## Installation
1. Ensure **Coal LLC** has Godot ModLoader 7.0.1 installed.
2. Place the packaged .zip file into your Coal LLC/mods/ directory.
3. Manage or toggle this mod directly via the in-game **Mod Manager**.
