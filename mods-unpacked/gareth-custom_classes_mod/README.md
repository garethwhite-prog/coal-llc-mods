# CUSTOM CLASSES MOD

**Namespace:** $namespace  
**Compatibility:** Coal LLC v1.4.1.1+ (ModLoader 7.0.1)

---

## Overview
Complete 9-Class Suite: Knight, Jedi, Bouncing Demolitionist, Rainbow Sinclairity, Void Siphon, Debt Executioner, Chrono-Industrialist, Gravitational Dreadnought, and Tectonic Fracker.

---

## Technical Details (For Modders)
Installs scripts and resources via Godot ModLoader 7.0.1 conventions. Modifies game state using native hook chains.

---

## Installation
1. Ensure **Coal LLC** has Godot ModLoader 7.0.1 installed.
2. Place the packaged .zip file into your Coal LLC/mods/ directory.
3. Manage or toggle this mod directly via the in-game **Mod Manager**.
