# The Debt Executioner Class

**Namespace:** $namespace  
**Compatibility:** Coal LLC v1.4.1.1+ (ModLoader 7.0.1)

---

## Overview
High-risk corporate class starting with late-game Onyx loadouts but saddled with -,000,000 corporate debt. Fail to meet daily quotas and corporate Repo Drones hunt you.

---

## Technical Details (For Modders)
Initializes Gvars.cash with a negative balance. Tracks daily interest and hooks day transition logic to spawn hostile aerial collector drones.

---

## Installation
1. Ensure **Coal LLC** has Godot ModLoader 7.0.1 installed.
2. Place the packaged .zip file into your Coal LLC/mods/ directory.
3. Manage or toggle this mod directly via the in-game **Mod Manager**.
