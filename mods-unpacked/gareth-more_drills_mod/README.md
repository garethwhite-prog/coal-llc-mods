# High-Yield Industrial Drills

**Namespace:** $namespace  
**Compatibility:** Coal LLC v1.4.1.1+ (ModLoader 7.0.1)

---

## Overview
Adds Tiers 5 through 10 of automated mining drill machinery with exponential mining damage scaling.

---

## Technical Details (For Modders)
Registers drill tiers into item_unlocks.tres and hooks drill_bit_2.gd to apply secondary drill speed scaling.

---

## Installation
1. Ensure **Coal LLC** has Godot ModLoader 7.0.1 installed.
2. Place the packaged .zip file into your Coal LLC/mods/ directory.
3. Manage or toggle this mod directly via the in-game **Mod Manager**.
