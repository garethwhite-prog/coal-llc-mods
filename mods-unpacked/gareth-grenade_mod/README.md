# Bouncing Grenade Arsenal

**Namespace:** $namespace  
**Compatibility:** Coal LLC v1.4.1.1+ (ModLoader 7.0.1)

---

## Overview
Adds 15 material grades of parabolic cluster grenades (Shoddy through Onyx) that rebound off solid subterranean geometry and detonate on timed fuses.

---

## Technical Details (For Modders)
Spawns rigidbodies with bounce physics materials and hooks collision impulses to trigger localized tile destruction.

---

## Installation
1. Ensure **Coal LLC** has Godot ModLoader 7.0.1 installed.
2. Place the packaged .zip file into your Coal LLC/mods/ directory.
3. Manage or toggle this mod directly via the in-game **Mod Manager**.
