# Overview

This mod adds an option to automatically open chests when you break one of the surrounding hard tiles.  
You can customize the priority of passives chosen by going to Settings -> PassiveOrder.

# Installation:
Place the zip in your game's mods directory, for example:  
`C:\Program Files (x86)\Steam\steamapps\common\Coal LLC\Coal LLC\mods`

# Mod Loader
This mod assumes you're using this fork of godot-mod-loader:  
https://github.com/NanobotZ/godot-mod-loader
