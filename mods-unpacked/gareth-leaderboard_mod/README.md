# Categorized Leaderboards & Hall of Fame

**Namespace:** gareth  
**Compatibility:** Coal LLC v1.4.1.1+ (ModLoader 7.0.1)

---

## Overview
Tracks all-time records across mining speed, damage, automated employee efficiency, and highest cash quotas, accessible directly from the Main Menu and Settings.

---

## Technical Details (For Modders)
Runs an autoload tracker node sampling Gvars.passives, Gvars.bonus_equipment_manager, and quota milestones every 1.0s. Persists records to user://leaderboard_records.json.

---

## Installation
1. Ensure **Coal LLC** has Godot ModLoader 7.0.1 installed.
2. Place the packaged .zip file into your Coal LLC/mods/ directory.
3. Manage or toggle this mod directly via the in-game **Mod Manager**.
