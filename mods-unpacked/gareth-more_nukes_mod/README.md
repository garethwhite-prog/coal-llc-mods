# Tactical Nukes Expansion

**Namespace:** $namespace  
**Compatibility:** Coal LLC v1.4.1.1+ (ModLoader 7.0.1)

---

## Overview
Registers 15 tiers of tactical nuclear ordnance into the equipment shop for late-game cavern excavation.

---

## Technical Details (For Modders)
Appends nuke item resources into item_unlocks.all_equipment_items with custom blast radii and cost progression.

---

## Installation
1. Ensure **Coal LLC** has Godot ModLoader 7.0.1 installed.
2. Place the packaged .zip file into your Coal LLC/mods/ directory.
3. Manage or toggle this mod directly via the in-game **Mod Manager**.
