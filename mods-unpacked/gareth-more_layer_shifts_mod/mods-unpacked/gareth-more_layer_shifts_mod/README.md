# Deeper Cavern Layer Shifts (6-12)

**Namespace:** $namespace  
**Compatibility:** Coal LLC v1.4.1.1+ (ModLoader 7.0.1)

---

## Overview
Extends subterranean mine generation from 6 up to 12 distinct geological strata, elevating high-tier mineral veins closer to reachable mining depths.

---

## Technical Details (For Modders)
Hooks adjust_level_bonus in tile_map_chunk.gd to extrapolate depth parameters beyond vanilla stratum bounds.

---

## Installation
1. Ensure **Coal LLC** has Godot ModLoader 7.0.1 installed.
2. Place the packaged .zip file into your Coal LLC/mods/ directory.
3. Manage or toggle this mod directly via the in-game **Mod Manager**.
