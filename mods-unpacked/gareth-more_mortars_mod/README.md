# Mortar Gun Artillery Expansion

**Namespace:** $namespace  
**Compatibility:** Coal LLC v1.4.1.1+ (ModLoader 7.0.1)

---

## Overview
Adds Tiers 6 through 10 of automated mortar gun emplacements with parabolic ballistic trajectory and massive area-of-effect shells.

---

## Technical Details (For Modders)
Injects mortar items into item_unlocks.tres and hooks shoot_mortar in mortar_manager.gd to scale shell velocities.

---

## Installation
1. Ensure **Coal LLC** has Godot ModLoader 7.0.1 installed.
2. Place the packaged .zip file into your Coal LLC/mods/ directory.
3. Manage or toggle this mod directly via the in-game **Mod Manager**.
