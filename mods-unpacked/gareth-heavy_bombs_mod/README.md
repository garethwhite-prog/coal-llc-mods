# Heavy Demolition Bombs

**Namespace:** $namespace  
**Compatibility:** Coal LLC v1.4.1.1+ (ModLoader 7.0.1)

---

## Overview
Adds Bunker Buster, Cryo-Cluster, and Thermobaric heavy bombs utilizing unused 32x32 animated bomb sheets with extended fuses and expanded blast radii.

---

## Technical Details (For Modders)
Registers HeavyBombEntity instances with customizable blast_radius (18-36 blocks) and custom damage scaling tied to Gvars.passives.bomb_damage.

---

## Installation
1. Ensure **Coal LLC** has Godot ModLoader 7.0.1 installed.
2. Place the packaged .zip file into your Coal LLC/mods/ directory.
3. Manage or toggle this mod directly via the in-game **Mod Manager**.
