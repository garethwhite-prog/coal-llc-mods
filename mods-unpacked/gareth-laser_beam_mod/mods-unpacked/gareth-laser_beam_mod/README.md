# High-Energy Laser Beam Weapon

**Namespace:** gareth  
**Compatibility:** Coal LLC v1.4.1.1+ (ModLoader 7.0.1)

---

## Overview
Adds a continuous energy beam weapon to the equipment shop using native shader and audio assets.

---

## Technical Details (For Modders)
Integrates shaders/laser.gdshader with audio streaming, performing continuous ray-march collision testing on TileMapManager.

---

## Installation
1. Ensure **Coal LLC** has Godot ModLoader 7.0.1 installed.
2. Place the packaged .zip file into your Coal LLC/mods/ directory.
3. Manage or toggle this mod directly via the in-game **Mod Manager**.
