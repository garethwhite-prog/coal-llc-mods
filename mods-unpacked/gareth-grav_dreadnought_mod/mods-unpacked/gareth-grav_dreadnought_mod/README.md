# Gravitational Dreadnought Class

**Namespace:** $namespace  
**Compatibility:** Coal LLC v1.4.1.1+ (ModLoader 7.0.1)

---

## Overview
Heavy armor class with high gravitational mass. Shotgun pellets and artillery shells fired enter a circular orbit around the player.

---

## Technical Details (For Modders)
Modifies bullet velocity vectors in _physics_process to apply centripetal acceleration relative to player global coordinates.

---

## Installation
1. Ensure **Coal LLC** has Godot ModLoader 7.0.1 installed.
2. Place the packaged .zip file into your Coal LLC/mods/ directory.
3. Manage or toggle this mod directly via the in-game **Mod Manager**.
