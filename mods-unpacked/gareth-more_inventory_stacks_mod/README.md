# Expanded Material Stack Sizes

**Namespace:** $namespace  
**Compatibility:** Coal LLC v1.4.1.1+ (ModLoader 7.0.1)

---

## Overview
Adds shop upgrades expanding carried ore stack sizes from 7 up to 16, allowing massive mining runs without overflowing.

---

## Technical Details (For Modders)
Modifies playerInventory stack clamping logic and injects stack expansion items into the equipment shop.

---

## Installation
1. Ensure **Coal LLC** has Godot ModLoader 7.0.1 installed.
2. Place the packaged .zip file into your Coal LLC/mods/ directory.
3. Manage or toggle this mod directly via the in-game **Mod Manager**.
