# 360-Degree Plasma Raygun

**Namespace:** $namespace  
**Compatibility:** Coal LLC v1.4.1.1+ (ModLoader 7.0.1)

---

## Overview
High-energy sidearm that fires a continuous 360-degree piercing energy beam on right-click.

---

## Technical Details (For Modders)
Hooks _physics_process in player_2.gd, calculating mouse aim vectors and raycasting tile damage along the line.

---

## Installation
1. Ensure **Coal LLC** has Godot ModLoader 7.0.1 installed.
2. Place the packaged .zip file into your Coal LLC/mods/ directory.
3. Manage or toggle this mod directly via the in-game **Mod Manager**.
