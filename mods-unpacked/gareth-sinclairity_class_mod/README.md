# Rainbow Sinclairity Class

**Namespace:** $namespace  
**Compatibility:** Coal LLC v1.4.1.1+ (ModLoader 7.0.1)

---

## Overview
Optics-focused mining class utilizing continuous prismatic beam energy that cuts stone without consuming standard pickaxe durability.

---

## Technical Details (For Modders)
Implements Line2D fractal Brownian motion beam rendering, casting linear ray-marches against tile collision masks with per-tick block health reduction.

---

## Installation
1. Ensure **Coal LLC** has Godot ModLoader 7.0.1 installed.
2. Place the packaged .zip file into your Coal LLC/mods/ directory.
3. Manage or toggle this mod directly via the in-game **Mod Manager**.
