# Expanded Hotbar Inventory Slots

**Namespace:** $namespace  
**Compatibility:** Coal LLC v1.4.1.1+ (ModLoader 7.0.1)

---

## Overview
Adds shop expansions increasing hotbar capacity from 4 slots up to 10 slots (+20 to +250 total capacity) scaling up to 2.5 Quadrillion.

---

## Technical Details (For Modders)
Adjusts player inventory slot limits and dynamically resizes UI hotbar containers.

---

## Installation
1. Ensure **Coal LLC** has Godot ModLoader 7.0.1 installed.
2. Place the packaged .zip file into your Coal LLC/mods/ directory.
3. Manage or toggle this mod directly via the in-game **Mod Manager**.
