# Cosmic Collectors Expansion

**Namespace:** $namespace  
**Compatibility:** Coal LLC v1.4.1.1+ (ModLoader 7.0.1)

---

## Overview
Adds 4 ultra-high-tier Collector drones with scaled cargo capacity, flight speeds, and non-blocking click-through tooltips.

---

## Technical Details (For Modders)
Extends employee_manager.gd hierarchy and patches employee_shop_tooltip.gd to prevent UI mouse blocking.

---

## Installation
1. Ensure **Coal LLC** has Godot ModLoader 7.0.1 installed.
2. Place the packaged .zip file into your Coal LLC/mods/ directory.
3. Manage or toggle this mod directly via the in-game **Mod Manager**.
