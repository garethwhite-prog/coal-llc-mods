# Mod Settings Compatibility Shim

**Namespace:** $namespace  
**Compatibility:** Coal LLC v1.4.1.1+ (ModLoader 7.0.1)

---

## Overview
A lightweight compatibility bridge ensuring third-party mods depending on legacy settings references continue operating seamlessly.

---

## Technical Details (For Modders)
Provides stub reference objects to satisfy ModLoader dependency resolution chains.

---

## Installation
1. Ensure **Coal LLC** has Godot ModLoader 7.0.1 installed.
2. Place the packaged .zip file into your Coal LLC/mods/ directory.
3. Manage or toggle this mod directly via the in-game **Mod Manager**.
