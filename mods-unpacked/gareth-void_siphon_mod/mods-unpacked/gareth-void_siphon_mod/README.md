# The Void Siphon Class

**Namespace:** $namespace  
**Compatibility:** Coal LLC v1.4.1.1+ (ModLoader 7.0.1)

---

## Overview
A hardcore class starting with zero mining tools. Uses gravitational implosions to collapse surrounding rock directly inward into mineral shards.

---

## Technical Details (For Modders)
Sets starting inventory data to an empty array. Hooks right-click input to iterate a 7x7 local grid, applying inward tile damage directly without tool requirements.

---

## Installation
1. Ensure **Coal LLC** has Godot ModLoader 7.0.1 installed.
2. Place the packaged .zip file into your Coal LLC/mods/ directory.
3. Manage or toggle this mod directly via the in-game **Mod Manager**.
