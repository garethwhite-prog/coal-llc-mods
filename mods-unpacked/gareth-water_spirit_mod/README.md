# Orbital Water Spirit Familiar

**Namespace:** $namespace  
**Compatibility:** Coal LLC v1.4.1.1+ (ModLoader 7.0.1)

---

## Overview
Summons an orbital cyan spirit familiar that circles the player, saturating surrounding rock strata with water to prime tiles for double wet damage.

---

## Technical Details (For Modders)
Spawns an orbital familiar node tracking player coordinates, applying wet tile status effects to all tiles within radius.

---

## Installation
1. Ensure **Coal LLC** has Godot ModLoader 7.0.1 installed.
2. Place the packaged .zip file into your Coal LLC/mods/ directory.
3. Manage or toggle this mod directly via the in-game **Mod Manager**.
