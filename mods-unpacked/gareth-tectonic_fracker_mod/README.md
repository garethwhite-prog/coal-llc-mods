# The Tectonic Fracker Class

**Namespace:** $namespace  
**Compatibility:** Coal LLC v1.4.1.1+ (ModLoader 7.0.1)

---

## Overview
Industrial seismic harvester that fires hydraulic acoustic drill pulses to shatter entire continuous ore seams simultaneously.

---

## Technical Details (For Modders)
Executes flood-fill graph searches across identical adjacent ore tile IDs, applying simultaneous destruction across connected mineral clusters.

---

## Installation
1. Ensure **Coal LLC** has Godot ModLoader 7.0.1 installed.
2. Place the packaged .zip file into your Coal LLC/mods/ directory.
3. Manage or toggle this mod directly via the in-game **Mod Manager**.
