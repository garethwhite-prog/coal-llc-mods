# Dual Multiplier Weapon Scaling

**Namespace:** $namespace  
**Compatibility:** Coal LLC v1.4.1.1+ (ModLoader 7.0.1)

---

## Overview
Adds compounding secondary multipliers (drill speed, axe speed, gun rate) to single-stat weapons for quadratic end-game scaling.

---

## Technical Details (For Modders)
Extends res://resources/passive_effects/passives.gd via ModLoader ScriptExtension to calculate compound stat products.

---

## Installation
1. Ensure **Coal LLC** has Godot ModLoader 7.0.1 installed.
2. Place the packaged .zip file into your Coal LLC/mods/ directory.
3. Manage or toggle this mod directly via the in-game **Mod Manager**.
