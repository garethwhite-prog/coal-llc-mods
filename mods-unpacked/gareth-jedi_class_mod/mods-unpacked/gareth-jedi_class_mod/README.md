# The Jedi Class

**Namespace:** $namespace  
**Compatibility:** Coal LLC v1.4.1.1+ (ModLoader 7.0.1)

---

## Overview
High-energy Force-wielder equipped with a piercing Energy Saber and rapid blaster sidearm for crowd control and fast cavern navigation.

---

## Technical Details (For Modders)
Employs shaders/laser.gdshader for collimated beam rendering combined with pistol bullet recoil scaling on Gvars.passives.

---

## Installation
1. Ensure **Coal LLC** has Godot ModLoader 7.0.1 installed.
2. Place the packaged .zip file into your Coal LLC/mods/ directory.
3. Manage or toggle this mod directly via the in-game **Mod Manager**.
