# Martial Artist Legends Expansion

**Namespace:** $namespace  
**Compatibility:** Coal LLC v1.4.1.1+ (ModLoader 7.0.1)

---

## Overview
Adds high-tier legendary boxing gloves and roundhouse kicks inspired by legendary fighters, featuring screen-clearing kinetic impact.

---

## Technical Details (For Modders)
Hooks attack_tile in boxing_gloves.gd and damage_tiles in kick.gd to apply compounding passive punch/kick damage.

---

## Installation
1. Ensure **Coal LLC** has Godot ModLoader 7.0.1 installed.
2. Place the packaged .zip file into your Coal LLC/mods/ directory.
3. Manage or toggle this mod directly via the in-game **Mod Manager**.
