# US-EXT-04: The Living Canvas Image Quantizer Subterranean Map
**Status:** In Progress
**Mod:** gareth-living_canvas_mod

**Description:**
As a player, I want to mine through custom subterranean strata sculpted directly from real images, photos, and screenshots using Euclidean color quantization.

**Acceptance Criteria:**
- Registered under map ID 103 with default theme 'Your Mum' beach mosaic.
- Converts RGB pixels from source images into corresponding rock types (Fire, Ice, Green, Dark Blue).
- Level select card for Map 103 hosts an in-card `📁 Browse Custom Image` button docked inside `MarginContainer/VBoxContainer`.
- Native OS FileDialog allows selecting custom PNG/JPG files and regenerating strata without restarting the client.
